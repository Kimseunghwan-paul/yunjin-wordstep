휴대폰에 설치하는 방법

  1. APK 파일 받기

    위 다운로드 버튼을 누르고 파일을 저장하세요.

  2. 받은 파일 열기

    휴대폰의 파일 앱에서 APK를 열어 설치하세요. 요청이 나오면 해당 파일 앱의 ‘이 출처 허용’을 설정하세요.

  3. 기존 앱 위에 업데이트

    앱을 삭제하지 않고 새 APK를 설치하세요. 같은 앱과 서명으로 업데이트하면 기존 별표와 학습 기록이 유지됩니다.
